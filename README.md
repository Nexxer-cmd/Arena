# CineBook — Vanilla HTML/CSS/JavaScript

This is a React-free recreation of the CineBook demo.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Home carousel
- Movies search/filter/sort
- Movie details
- Cinemas + cinema details
- Login/register/logout
- Profile
- My Bookings
- Offers
- Date → Show → Seats → Summary → Confirmation booking flow
- Seat availability persisted per show
- Admin panel: Movies, Cinemas, Shows, Bookings, Users
- localStorage persistence
